# Dinero-bogføring med AI 🤖📗

Automatiseret bogføring i Dinero fra ende til anden: AI'en læser dit bankkontoudtog, finder de
manglende bilag i din mail og dine mapper, undersøger gældende lovgivning, opretter alt som
kladder via Dineros API — og bogfører først når **du** har godkendt. Til sidst afstemmes banken
til 0,00 kr afvigelse.

## Kom i gang på 3 trin

1. **Klon eller download** denne mappe
2. **Åbn [Claude Code](https://claude.com/claude-code)** i mappen
3. Skriv: **"sæt det op"**

AI'en klarer resten: installerer skillen, guider dig til API-adgang i Dinero, tester forbindelsen
og fortæller dig præcis hvad du skal gøre for at starte første oprydning.

## Krav

- **Dinero Pro eller Total** (API'et findes ikke på gratis- og Starter-abonnementer)
- Claude Code på macOS eller Linux
- 10 minutter + en kop kaffe (Dinero sender API-nøglerne på mail, typisk inden for få timer)

## Hvad den gør

1. Lægger en plan og stiller de spørgsmål, den er i tvivl om
2. Undersøger gældende dansk lovgivning fra autoritative kilder — og viser dig kilderne
3. Parser dit kontoudtog og validerer det mod slutsaldoen
4. Matcher banken mod bogholderiet og rapporterer, hvad der mangler
5. Jagter bilag i mail, lokale mapper og leverandørportaler
6. Klassificerer alt med konto og momskode — tvivl afklares med dig
7. Opretter alt som **kladder** i Dinero med bilag vedhæftet
8. **Du godkender** — først derefter bogføres der
9. Afstemmer banken til 0,00 kr afvigelse

## Sikkerhed

- Intet bogføres uden din eksplicitte godkendelse
- Skillen indeholder ingen lovpåstande — AI'en researcher gældende regler ved hver brug og viser kilder
- Dine API-nøgler ligger i miljøvariabler på din egen maskine — aldrig i denne mappe, aldrig i git
- Værktøjet erstatter ikke din revisor — ved væsentlige eller tvivlsomme forhold: spørg en professionel
